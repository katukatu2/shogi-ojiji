## 所見

### 1. `logs/` に置いた試験の写しが `npm test` を壊している【要対応・実装の欠陥ではない】

`logs/task-progress/task-progress.spec.ts` が `tests/e2e/task-progress.spec.ts` の写しとして存在し、vitest がこれを拾って読み込みに失敗する。


`vite.config.ts:16` の `exclude` は `tests/**` と `**/.claude/**` を除くが、**`logs/**` を除いていない**。

Codex の報告が誤っているわけではない。`logs/task-progress/unit.txt` は 12:55:30、写しの更新時刻は 12:52:48 だが、これは `tests/e2e/` 側と**寸分違わぬ時刻と大きさ**なので、時刻を保ったまま後から複製したものである。**単体を走らせた時点では存在しなかった**と見るのが自然で、報告の 349 件成功はその時点では正しい。

影響の範囲を正確に書く。

- `logs` は `.gitignore:4` に入っているので、**コミットにも CI にも乗らない**。製品への影響は無い。

**対応**: 写しを消せば直る。加えて `vite.config.ts` の `exclude` に `logs/**` を足すことを勧める。`logs/` は証拠の置き場なので、今後も試験の写しが入る。二度目なので、次を防ぐ側を直したい。
