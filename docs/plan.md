# 将棋オジジの定石指南（仮） 企画書 v0.3

作成日: 2026-09-04

## 一言コンセプト

オジジは毎回、得意戦法で囲ってくる。プレイヤーは自由に指してよい。
ただし「その戦法相手にやってはいけない手」を指すと、頑固オヤジが乱入して叱り、正しい手を教えてくれる。
勝つためというより、「矢倉にはこう戦う」を体で覚える将棋。

（v0.2 までは「プレイヤーが矢倉を組む練習」だったが、2026-09-04 のプレイ感想「真っすぐ組まないと叱られるのは楽しくない」を受け、オジジが戦法を指す側に変更した。）

## ターゲット

- 将棋のルールは知っているが、序盤で何を指せばいいか分からない初心者〜初級者
- スマホで 5〜10 分の隙間時間に遊びたい人

## キャラクター「オジジ」

- 海原雄山の威圧感と波平の頑固さを足して 2 で割った老人。
- 見た目はキャラクターコンセプト「雷蔵」（2026-09-06 にユーザーが提示）に合わせる。白い逆立った髪、太い黒眉、丸くて赤ら顔、茶の着物に生成りの羽織（紋つき）、手には王将の駒。以前の「ツルツル頭・顎ひげ」案は廃止。
- 2026-09-06 に制作元から納品されたパーツアニメーション（`<raizo-rig>`、透過 PNG 17 点）に置き換えた。8 状態（idle / thinking / nod / good / doubtful / bad / angry / surprised）をゲームの出来事に連動させる。SVG 版はフォールバックとして残す。
- 口癖は「ばかもーん！」。叱った直後に、意外と丁寧に理由を教えてくれる。
- 良い手を指すと無言で頷くだけ（褒めない）。

## ゲームの流れ

1. タイトル画面で「オジジの○○に挑む」を選ぶ（初回は矢倉のみ）。
2. 対局画面は盤面と持ち駒のみ。プレイヤーは先手固定で自由に指す。オジジ（後手）は選んだ戦法で囲ってくる。
3. プレイヤーが手を指すたびに判定する。
   - 問題ない手なら何も起きない。
   - 対矢倉のポイントを突く良い手（角交換、端攻め、棒銀など）には無言で頷き、一言添える。
   - その戦法相手の NG や、エンジンが大きく形勢を損ねると判定した手なら、オジジの顔がカットインし「ばかもーん！」と鳴る。
4. カットイン中に「なぜダメか」「正しい手はどれか」「形勢の変化」を表示し、盤上に正解の手を緑でハイライトする。
5. プレイヤーは「指し直す」か「このまま進む」を選べる。
6. 対局終了後、「叱られた回数」「オジジが認めた手」「その戦法との戦い方」を表示する。

## 悪手判定の仕組み

| 反応 | 条件 | 例 |
|---|---|---|
| ばかもーん！（カットインで手を止める） | 戦法ごとの NG パターン（一局に一度ずつ）。将棋エンジン（やねうら王 WASM）で指す前後の評価値を比べ、300 点以上落ちた手。詰みの見逃し、詰まされる手 | 玉を囲わずに攻め駒を前に出す、飛車の隣に玉を寄せる、角をタダで取られる手 |
| 無言で頷く | その戦法相手の良い手の形（一局に一度ずつ） | 角交換「矢倉党は角を換えられるのを嫌う」、端攻め「端は矢倉の泣き所」 |

- 「問題ない手を叱らない」を最優先にしている。定跡から外れただけでは何も言わない。
- カットインには「形勢 +17 → -2680」のように評価値の変化と、相手の狙いの手（読み筋の初手）を表示する。
- オジジの駒組みは戦法ごとの優先リスト（`plan`）。合法で、エンジンが損しないと言う手を上から順に指す。相手が角交換を狙えば先に角道を止める、といった対応はエンジン判定で自然に入る。駒組みが終わるか、王手や駒得の場面ではエンジンの候補手から最善に近い手をランダムに選ぶ。
- エンジンが使えない環境では、駒損と一手詰めだけの簡易判定に切り替わる。

- 戦法は `src/style/*.ts`（駒組みの優先リストと教訓）、NG・良い手の形は `src/style/patterns.ts` に書く。

## 収録する戦法（オジジが指す側）

- 矢倉（実装済み）: 後手矢倉。玉２二、金３二・４三、銀３三。標準型・飛車先速攻型・早囲い型
- 四間飛車（実装済み 2026-09-06）: 飛車４二、美濃囲い。美濃囲い型・藤井システム風・振り飛車穴熊型
- 角換わり（実装済み 2026-09-06）: 一手損角換わり。腰掛け銀型・早繰り銀型・棒銀型
- 棒銀（実装済み 2026-09-06）: 飛車先を伸ばし銀を８四へ。本格型・速攻型
- 中飛車（実装済み 2026-09-06）: ゴキゲン中飛車。標準型・早囲い型

## 技術構成

- TypeScript + Vite。フレームワークなし。
- 将棋のルール処理は自前実装（`src/engine`）。形勢判定とオジジの指し手はやねうら王 WebAssembly 版（`@mizarjp/yaneuraou.k-p`、評価関数内蔵で約 2.6 MB、GPLv3）。
- GPLv3 のため、このアプリのソースも公開する（2026-09-04 にユーザーが決定）。iOS App Store は GPL との相性問題があるため、まず Web と Android を対象にする。
- スマホ化は Capacitor で iOS / Android にパッケージ化する（README 参照）。
- 音声は `public/sfx/bakamon.mp3` があればそれを使い、無ければブラウザの音声合成で代用。
- 顔は SVG で描画（`src/ui/ojiji.ts`）。差し替え可能。

## MVP の範囲（実装済み）

- オジジの矢倉 1 戦法
- 盤面、持ち駒、成り、反則チェック（二歩・打ち歩詰め・行き所のない駒）
- エンジン判定と NG パターンによる悪手カットイン、解説、指し直し
- 良い手への頷きと一言
- 対局終了時のまとめ画面

## 学習ループ（2026-09-08 追加）

- 難易度 3 段階（見習い・門下生・師範代）でオジジの強さを変え、初心者が勝てる入口を作る。
- 対局ごとの「今日の課題」と、勝利数＋課題達成による昇級。
- 結果画面に「今日の 3 手」（形勢が最も動いた手を盤面つきで）。
- 公開品質: 画像を WebP 化、Service Worker でオフライン対応、エンジン不可時の案内、CI、Capacitor 設定。
