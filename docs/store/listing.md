## 短い説明（80 字以内）

## 詳しい説明

オジジは毎回、得意戦法で囲ってきます。あなたは先手で、好きなように指してかまいません。
ただし「その戦法相手にやってはいけない手」を指すと、オジジが割り込んで「ばかもーん！」と叱り、正しい手を教えてくれます。
勝つためというより、「矢倉にはこう戦う」「四間飛車には急戦か持久戦か」を体で覚えるための将棋です。

■ 学習の仕組み
・一手指すたびに、将棋エンジン（やねうら王）が形勢を判定します。
・反応は 5 段階。無言で頷く ＞「良い手じゃな。だがワシならこう打つな」＞「むう…」＞「それは悪手じゃろう」＞「ばかもーん！」。下の二つは手を止めて、指し直せます。
・叱るときは「正解の手」「指した手」「形勢の変化」「なぜその手なのか」を盤の上で示します。
・勝っているうちは細かいことを言いません。本当に形勢が崩れる手だけ止めます。
・「ヒント」でオジジならどう指すかを見られ、「待った」で一組戻せます。
・対局ごとに「今日の課題」（角交換をする、囲ってから攻める、ばかもんゼロ、など）が一つ出ます。
・対局後は「今日の 3 手」。形勢が最も動いたあなたの手を、盤面つきで振り返れます。

■ オジジの 5 戦法
・矢倉（標準型・飛車先速攻型・早囲い型）
・四間飛車（美濃囲い型・藤井システム風・振り飛車穴熊型）
・角換わり（腰掛け銀型・早繰り銀型・棒銀型）
・棒銀（本格型・速攻型）
・中飛車（ゴキゲン標準型・早囲い型）
戦法ごとに、駒組みの節目の独り言、良い手への頷き、やってはいけない形、対局後の教えがあります。

■ 強さは 3 段階
・見習い: 初心者でも勝てる強さ。まずはここから。
・門下生: 見習いから一歩進んだ強さ。設定から自由に選べます。
・師範代: 本気のオジジ。
難易度で変わるのはオジジの指し手の精度だけで、囲い方は同じです。

■ 判定はやねうら王
形勢の判定とオジジの指し手には、将棋エンジン「やねうら王」（WebAssembly 版、評価関数は水匠 Petite）を使っています。
判定は端末内で行います。Web版は初回に必要なデータの読み込みが必要です。エンジンを使えない環境では簡易判定に切り替わります。iPhone・Androidアプリの本格判定は実機確認後に案内を確定します。

■ こんな人に
・将棋のルールは知っているけれど、序盤で何を指せばいいか分からない
・スマホで 5〜10 分の隙間時間に、少しずつ上達したい
・「なぜその手がダメなのか」を、その場で教わりたい

■ 安心して使えます
・広告なし、アカウント登録なし、個人情報の収集なし。
・アプリは学習の進み具合を端末内に保存します。OS・ブラウザのバックアップ設定は各サービスの扱いに従います。
・GPLv3でのソース公開を準備中です。公開先を確定してから提供を開始します。

## スクリーンショット案（5 枚）

原案は `npm run store:shots -- <保存先>` で生成する。開発サーバーを 5179 番で起動しておく。
01〜05 は Web 実画面の 1080×1920、06 は 1024×500 の横長原案。最終提出は各ストアの現行要件を確認し、対象端末で撮り直す。

| # | 画面 | 撮る場面 | 見せたいこと |
|---|---|---|---|
| 1 | タイトル | 全身のオジジと題名、「はじめる」ボタン | キャラクターと世界観 |
| 2 | 対局設定 | 四間飛車を選んだ一覧 | 5戦法と3段階の強さ |
| 3 | 対局 | 棒銀・見習いの開始盤面 | 盤と持ち駒、ヒント・待ったの操作 |
| 4 | 対局（指導） | ▲４八玉で玉飛接近を指導する実際の場面 | 一手の理由を学び、指し直せる |
| 5 | 結果 | 同じ対局を投了した結果 | 課題と再戦の流れ |

- 各画像に短い見出しを載せるなら、上部に 1 行（例: 「やってはいけない手は、その場で叱られる」）。文字は画像の 20% 以内に収める。
- フィーチャーグラフィック（1024×500）も要る。タイトル画面のオジジと題名を横長に組み直したものを用意する（アプリ内の素材 `public/raizo/body.webp` と顔を使う）。
- ストア用のアイコンは `public/icons/icon-512-square.png`（512×512、四隅まで地の色。角の丸めは Play が行う）。`npm run icons` で `public/icon.svg` から作る。
