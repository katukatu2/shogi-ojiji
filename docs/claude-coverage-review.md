## 2. 角交換の課題 ID — 修正確認

**条件の妥当性**: 取られた駒だけでなく、取る側と交換の成立を見るようになった。

- `takingBack`: 自分の角が盤上に残っておらず、相手が角を持ち駒にしている（＝自分の角を取られた後の取り返し）。
- `offeringTrade`: 自分の角か馬で取り、指した後に相手がその地点へ指せる合法手がある（＝取り返される交換）。
- どちらでもなければ課題 ID を付けない。

**反例と正例**: `src/style/bishop-exchange.test.ts` が、製品で問題になった実棋譜（21 手目 `▲４四桂`）を再生し、自分の角が 8八 に残っていること・指した駒が桂であることを確かめた上で ID が立たないことを検査する。正例は「先手から角を交換する」と「後手からの角交換を銀で取り返す」の 2 つ。実行して通過を確認した。

**取りこぼしの確認**: 自分の角で相手の角を取り、相手が取り返せない場合（ただ取り）は ID が立たない。これは交換ではないので正しい絞り込みで、取りこぼしではない。取り返しを金でした場合も `takingBack` は駒種を見ないので立つ。

**製品での確認**: `scripts/product-playthrough.ts` が、実際に駒を捕獲した記録から交換の有無を判定し、交換していない対局では `tasksDone` に `yagura:bishop-exchange` が入らないことを検査している。開発 API を使わず盤と持ち駒だけを操作しており、局面や進捗を注入していない。

## 3. CI が自動対局の例外を拾うか — 修正確認

**終了コード**: `process.exit(failures > 0 ? 1 : 0)` になった。対局ごとの例外は数えた上で後続の対局を続け、エンジンの初期化自体が失敗した場合も数える。`finally` で `engine?.terminate()` を必ず呼ぶ。**後続の実行・記録・終了処理はいずれも維持されている。**

**試験**: `scripts/selfplay.test.ts` が `Position.initial` に例外を注入し、2 局とも記録が残ること、`terminate` が 1 回呼ばれること、`process.exit(1)` が呼ばれることを検査する。実行して通過を確認した。

**CI 側**: 5 戦法のループはステップ既定の `bash -e` で走るため、1 戦法が非ゼロで終われば以降を打ち切ってステップが失敗する。自動対局ログの保存（`if: always()`）と `workflow_dispatch` も入った。Android の CI に Build-Tools 35 を明示した変更も、AGP 8.13 の実要求と整合する。

## 新規欠陥

### 存在しない戦法を指定しても、黙って矢倉に読み替えて成功する（low）

- **場所**: `scripts/selfplay.ts:60`（`const STYLE = findStyle(STYLE_ID) ?? STYLES[0];`）
- **再現**:
  ```bash
  npx vite-node scripts/selfplay.ts -- --style nonexistent --games 1 --plies 10 --out logs/bad.jsonl
  echo $?      # → 0
  head -1 logs/bad.jsonl   # → {"game":0,"style":"yagura",...}
  ```
- **期待**: 知らない戦法 id を渡したら失敗し、終了コード 1 を返す。CI の 5 戦法ループが全戦法を実際に走らせたことを保証する。
- **実際**: 矢倉に読み替えて正常終了する。ログの `style` 欄には `yagura` と残るが、誰も落ちない。`.github/workflows/ci.yml` のループで戦法 id を打ち間違えたり、`src/style/index.ts` から戦法を消したり id を変えたりしても、CI は緑のまま矢倉を 5 回試すだけになる。今回の修正で「例外は拾う」ようになったが、「5 戦法を実際に試した」ことは依然として保証されていない。
- **修正案**: `findStyle` が `undefined` を返したら既知の id 一覧を出して `process.exit(1)` する。あわせて CI のループを `STYLES` の id から生成するか、`selfplay` に「全戦法を回す」引数を足せば、ループ側の一覧と実体のずれも防げる。
- **補足**: この行自体は今回の差分より前から存在する。3 点目の「CI が自動対局の問題を拾うか」を確かめる過程で見つけたので、ここに記す。
